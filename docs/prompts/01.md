# Anti-pattern risolto

**Non** aggiungere `Folio::path(...)` in `ActivityServiceProvider`.

Activity possiede i file in `resources/views/pages/`; il mount è di
`Cms/FolioVoltServiceProvider` (locale + `/api`).
